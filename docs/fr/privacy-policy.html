Politique de confidentialité

Dernière mise à jour : 28 mai 2026

Votre confidentialité nous est importante. UnderPressure a été conçu comme un journal personnel de bien-être où toutes les données sont stockées exclusivement sur votre appareil. Cette Politique de Confidentialité explique quelles données sont collectées, comment elles sont utilisées et quels droits vous avez.

1. Collecte de données

UnderPressure ne collecte aucune donnée personnelle automatiquement.

Toutes les informations sont saisies manuellement par vous. L'application n'accède pas aux capteurs, contacts, données de localisation ou autres données système. Vous avez un contrôle total sur ce que vous enregistrez.

Vous pouvez saisir manuellement les types de données suivants :

  • Lectures et observations quotidiennes
  • Notes et réflexions personnelles
  • Mesures et trackers personnalisés
  • Suivis de bien-être
  • Toute information personnelle que vous choisissez d'enregistrer

2. Stockage des données

Toutes les données sont stockées exclusivement sur votre appareil.

L'application :

  • n'envoie aucune donnée aux serveurs
  • ne synchronise aucune donnée avec les services cloud
  • n'utilise aucune base de données externe
  • ne partage aucune donnée avec des tiers

Vous conservez le contrôle total de vos données en permanence.

3. Conservation et suppression des données

Les données utilisateur sont stockées sur votre appareil et y restent jusqu'à ce que vous les supprimiez manuellement.

Vous pouvez supprimer vos données de les façons suivantes :

  • Supprimer toutes les données de l'application : Utilisez les paramètres de l'application pour supprimer toutes vos entrées et notes enregistrées.
  • Effacer les données d'application (Android) : Allez à Paramètres de l'appareil → Applications → UnderPressure → Stockage → Effacer les données. Cela supprime toutes les données stockées par l'application.
  • Désinstaller l'application (Android) : Appuyez longuement sur l'icône de l'application UnderPressure sur votre écran d'accueil ou votre tiroir d'applications, puis sélectionnez "Désinstaller" et confirmez. Vous pouvez également désinstaller via Paramètres de l'appareil → Applications → UnderPressure → Désinstaller. Cela supprime l'application et toutes les données associées de votre appareil.

4. Partage de données

L'application inclut des fonctions de partage et d'exportation facultatives.

Les données ne sont partagées ou exportées que si vous choisissez explicitement de le faire. L'application n'envoie ni ne télécharge jamais les données automatiquement.

5. Aucun service tiers

UnderPressure n'utilise pas :

  • Outils d'analyse
  • Réseaux publicitaires
  • Bibliothèques de suivi
  • SDK tiers
  • Liens externes

Il n'y a pas de publicité, pas de paiements et pas d'abonnements.

6. Sécurité

Comme toutes les données restent sur votre appareil, leur sécurité dépend de :

  • du système d'exploitation de votre appareil
  • des paramètres d'écran de verrouillage et de sécurité de votre appareil

L'application ne transmet ni n'expose vos données en externe.

7. Informations pour les utilisateurs

UnderPressure fournit des références informatives sur le rythme quotidien, les états d'équilibre, les niveaux d'activité, les modèles de récupération et les routines de bien-être personnel. Il s'agit uniquement de références éducatives et ne constituent pas un avis médical ou des conseils professionnels.

8. Confidentialité des enfants

UnderPressure n'est pas destiné aux enfants et ne collecte aucune donnée automatiquement. Toutes les données sont saisies manuellement par l'utilisateur et ne sont pas personnalisées.

9. Modifications de cette politique

Si cette politique de confidentialité change, la version mise à jour sera publiée à cette URL.
