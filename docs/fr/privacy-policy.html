Politique de confidentialité

Dernière mise à jour : 24 mai 2026

Votre vie privée est importante pour nous. UnderPressure a été conçu pour stocker vos mesures de santé exclusivement sur votre appareil. Cette politique de confidentialité explique quelles données sont collectées, comment elles sont utilisées et quels droits vous avez.

1. Collecte de données

UnderPressure ne collecte aucune donnée personnelle automatiquement.

Toutes les informations sont saisies manuellement par vous à l'aide du bouton "Ajouter". L'application n'accède pas aux capteurs, contacts, données de localisation ou autres données système.

Vous pouvez saisir les données suivantes :

  • Mesures de la tension artérielle
  • Valeurs de fréquence cardiaque
  • Horodatages des mesures
  • Suivi personnalisé de votre choix (texte, nombre, case à cocher)

2. Stockage des données

Toutes les données sont stockées exclusivement sur votre appareil.

L'application :

  • n'envoie aucune donnée aux serveurs
  • ne synchronise aucune donnée avec les services cloud
  • n'utilise aucune base de données externe
  • ne partage aucune donnée avec des tiers

Vous conservez le contrôle total de vos données en permanence.

3. Conservation et suppression des données

Les données utilisateur sont stockées sur votre appareil et y restent jusqu'à ce que vous les supprimiez manuellement.

Vous pouvez supprimer vos données de les façons suivantes :

  • Supprimer toutes les données de l'application : Utilisez l'option "Paramètres" → "Supprimer toutes les données" dans l'application pour supprimer toutes vos mesures enregistrées.
  • Effacer les données d'application (Android) : Allez à Paramètres de l'appareil → Applications → UnderPressure → Stockage → Effacer les données. Cela supprime toutes les données stockées par l'application.
  • Désinstaller l'application (Android) : Appuyez longuement sur l'icône de l'application UnderPressure sur votre écran d'accueil ou votre tiroir d'applications, puis sélectionnez "Désinstaller". Vous pouvez également désinstaller via Paramètres de l'appareil → Applications → UnderPressure → Désinstaller. Cela supprime l'application et toutes les données associées de votre appareil.

4. Partage de données

L'application inclut une fonction de partage facultative.

Les données ne sont partagées que si vous choisissez explicitement de le faire via le menu de partage de votre appareil. L'application n'envoie ni ne télécharge jamais les données automatiquement.

5. Aucun service tiers

UnderPressure n'utilise pas :

  • Outils d'analyse
  • Réseaux publicitaires
  • Bibliothèques de suivi
  • SDK tiers
  • Liens externes

Il n'y a pas de publicité, pas de paiements et pas d'abonnements.

6. Sécurité

Comme toutes les données restent sur votre appareil, leur sécurité dépend de :

  • du système d'exploitation de votre appareil
  • des paramètres d'écran de verrouillage et de sécurité de votre appareil

L'application ne transmet ni n'expose vos données en externe.

7. Confidentialité des enfants

UnderPressure n'est pas destiné aux enfants et ne collecte aucune donnée automatiquement. Toutes les données sont saisies manuellement par l'utilisateur et ne sont pas personnalisées.

8. Modifications de cette politique

Si cette politique de confidentialité change, la version mise à jour sera publiée à cette URL.
