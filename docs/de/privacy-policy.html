Datenschutzerklärung

Aktualisiert am: 23. April 2026

Ihre Privatsphäre ist wichtig. UnderPressure wurde entwickelt, um Ihre gesundheitsbezogenen Messwerte ausschließlich lokal auf Ihrem Gerät zu speichern. Diese Datenschutzerklärung erläutert, welche Daten erfasst werden, wie sie verwendet werden und welche Rechte Sie haben.

1. Datenerfassung

UnderPressure erfasst keine personenbezogenen Daten automatisch.

Alle Informationen werden manuell vom Nutzer eingegeben, indem die „Hinzufügen"-Schaltfläche verwendet wird. Die App greift nicht auf Sensoren, Kontakte, Standortdaten oder andere Systemdaten zu.

Sie können folgende Daten eingeben:

  • Blutdruckwerte
  • Pulswerte
  • Zeitstempel der Messungen
  • Benutzerdefinierter Tracker Ihrer Wahl (Text, Zahl, Kontrollkästchen)

2. Datenspeicherung

Alle Daten werden ausschließlich auf Ihrem Gerät gespeichert.

Die App:

  • sendet keine Daten an Server
  • synchronisiert keine Daten mit Cloud-Diensten
  • verwendet keine externen Datenbanken
  • teilt keine Daten mit Dritten

Sie behalten jederzeit die volle Kontrolle über Ihre Daten.

3. Datenweitergabe

Die App enthält eine optionale Teilen-Funktion.

Daten werden nur dann geteilt, wenn Sie dies ausdrücklich über das Teilen-Menü Ihres Geräts auswählen. Die App sendet oder lädt niemals automatisch Daten hoch.

4. Keine Dienste von Drittanbietern

UnderPressure verwendet keine:

  • Analyse-Tools
  • Werbenetzwerke
  • Tracking-Bibliotheken
  • Drittanbieter-SDKs
  • externen Links

Es gibt keine Werbung, keine Zahlungen und keine Abonnements.

5. Sicherheit

Da alle Daten auf Ihrem Gerät verbleiben, hängt deren Sicherheit ab von:

  • dem Betriebssystem Ihres Geräts
  • den Sperrbildschirm- und Sicherheitseinstellungen Ihres Geräts

Die App überträgt oder exponiert Ihre Daten nicht nach außen.

6. Datenschutz für Kinder

UnderPressure richtet sich nicht an Kinder und erfasst keine Daten automatisch. Alle Daten werden manuell vom Nutzer eingegeben.

7. Änderungen dieser Richtlinie

Wenn sich diese Datenschutzerklärung ändert, wird die aktualisierte Version unter dieser URL veröffentlicht.
