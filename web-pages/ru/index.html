UnderPressure

Приложение для отслеживания артериального давления

Добро пожаловать

UnderPressure - это простое и конфиденциальное мобильное приложение для отслеживания показаний артериального давления и пульса на устройстве Android.

Все ваши данные остаются на вашем устройстве - мы не собираем, не храним и не делимся никакой информацией о здоровье с третьими лицами.

Особенности

✓ Локальное хранение данных - все измерения остаются на вашем устройстве
✓ Интуитивный интерфейс для записи артериального давления и пульса
✓ Учетная запись не требуется
✓ Без реклам и отслеживания
✓ Делитесь данными только когда хотите
