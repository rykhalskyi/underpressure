UnderPressure

Додаток для відстеження артеріального тиску

Ласкаво просимо

UnderPressure - це простий і приватний мобільний додаток для відстеження вимірювань артеріального тиску та пульсу на вашому пристрої Android.

Усі ваші дані залишаються на вашому пристрої - ми не збираємо, не зберігаємо та не ділимося будь-якою інформацією про здоров'я з третіми сторонами.

Функції

✓ Локальне зберігання даних - всі вимірювання залишаються на вашому пристрої
✓ Простий інтерфейс для запису артеріального тиску та пульсу
✓ Обліковий запис не потрібен
✓ Без реклами та відстеження
✓ Ділитися даними тільки коли хочете
